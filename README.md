# Car Marketplace

## Overview

A modern, responsive car marketplace concept built as a frontend portfolio project. The experience brings vehicle discovery, saved cars, dealer profiles, and seller tools together in a polished single-page application.

## Features

- Responsive homepage
- Car browsing, search, filters, and sorting
- Individual car detail pages with image galleries
- Saved cars with local persistence and cross-tab synchronization
- Dealer directory and dealer profile pages
- Sell Your Car demo form with save-and-resume listing drafts
- Contact Dealer and Schedule Test Drive demo flows
- About and Contact pages
- Responsive mobile, tablet, and desktop layouts
- Login and signup interface demonstrations

## Tech Stack

- React
- Vite
- JavaScript (ES modules)
- HTML
- CSS
- Node.js and npm

## Run Locally

Requirements: Node.js and npm.

```sh
npm install
npm run dev
```

Create and preview a production build:

```sh
npm run build
npm run preview
```

## Deploy

The project is configured for Vercel. Import the GitHub repository into Vercel and use the Vite defaults:

- Build command: `npm run build`
- Output directory: `dist`

The Vercel rewrite configuration serves the single-page application for direct visits to car and dealer routes.

## Portfolio Note

This is a fictional marketplace for portfolio demonstration. Marketplace interactions, saved listings, authentication screens, and forms are demo functionality; they do not process real vehicle sales or payments, provide real authentication, or send communications to dealers.
